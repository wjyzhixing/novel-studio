# 顶部栏项目菜单与右侧栏切换设计

## 目标

调整工作台顶部栏的信息层级：将备份与索引维护操作收纳到左上角项目菜单；将右侧栏切换按钮放到当前模型按钮左侧，并确保右侧栏收起后其内容完全不可见。

## 交互设计

- 项目名称按钮继续展示当前项目名，并作为项目菜单触发器。
- 项目菜单包含“创建备份”“创建增量”“修复索引”三个入口。
- 三个入口复用现有 `BackupActions` 的业务逻辑与顶部通知反馈。
- 点击菜单外部或按 `Escape` 关闭项目菜单。
- 顶部栏右侧新增单个 Agent 图标按钮，位于模型按钮左侧，继续切换右侧栏展开/收起状态；展开时高亮，收起时显示为灰色。
- 右侧栏收起时不展示其内容，仅保留窄的切换入口；再次点击后恢复右侧栏。

## 组件与数据流

- `App.tsx` 负责项目菜单开关、外部关闭、右侧栏状态和顶部按钮布局。
- `BackupActions.tsx` 负责备份、增量备份和修复索引的操作逻辑；通过受控 action 接收菜单触发命令，并在完成后向 `App` 发送通知。
- `RightPanel` 的 `collapsed` 状态继续由 `App` 管理；收起分支不渲染右侧栏正文，避免内容残留或占用可见区域。

## 验证

- 静态检查确认顶部栏不再直接展示三个备份操作按钮。
- 组件测试确认项目菜单入口可触发三项操作，右侧栏按钮可切换状态。
- 运行项目既有 typecheck/build/test 检查，确保现有备份流程和工作台布局不回归。
