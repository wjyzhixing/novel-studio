# Novel Studio 项目目录

- `chapters/`：章节 Markdown 正文；场景元数据使用同名 `.scenes.yaml`
- `story/`：前提、大纲、时间线、关系、伏笔和卷结构
- `characters/`：角色 YAML 设定
- `world/`：地点、组织、物品和 Lore 设定
- `workflows/`：可视化 DAG 工作流定义
- `prompts/`：版本化 Prompt Pack
- `assets/characters/`：角色参考图
- `assets/scenes/`：场景图片和 Asset provenance
- `assets/covers/`：封面与宣传视觉
- `.novel/`：SQLite 索引、Revision、Checkpoint、缓存和运行日志（不要手动删除）
