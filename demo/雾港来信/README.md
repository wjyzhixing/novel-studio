# 雾港来信

《雾港来信》是一部都市悬疑 / 成长题材中文中篇小说示例，目标篇幅为 3–5 万字，采用三幕十四章结构。

## 故事入口

旧录音修复师林岚收到一盘来自十五年前的损坏磁带，里面有失踪父亲的求救声。她要查清录音从哪里来，也必须面对父亲当年刻意隐藏的代价。故事从修复店、匿名包裹和一段无法解释的噪声开始，不在第一章直接揭示中心谜团。

## 使用方式

1. 在 Novel Studio 中打开本目录。
2. 配置一个可用的 Provider，并确认项目没有把密钥写入文件。
3. 打开左侧的“创作流程”，查看 `story/authoring-progress.yaml` 对应的全书阶段。
4. 在“章节计划”中选择要写的章节，点击“运行创作流程”；这会运行 `flow_my_authoring`。旧版 `flow_middle_novel_authoring` 仍保留在项目中，可用于对照或回滚。
5. 流程会先生成 Context、规划和草稿，再并行进行角色、逻辑、文风检查。
6. 流程停在 Human Review 后，查看 Diff，选择接受、拒绝或编辑草稿。
7. 只有审核通过后正文才会写回 Markdown，并生成 Revision；随后 Memory Extract 只产生候选事实。
8. 在 Canon Review 中检查候选事实，人工应用或撤回，再回到创作流程推进下一章。

新项目从欢迎页点击“创建新项目”后会进入创作向导，填写题材、Premise、章节数、卷名和章节标题即可生成同样的基础结构。完成所有章节人工审核、Canon 处理和全稿修订后，先点击“检查全书”，通过门禁后再导出终稿。
